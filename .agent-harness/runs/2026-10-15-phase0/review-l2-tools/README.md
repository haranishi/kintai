# 査読 L2 が使った道具

独立した読み取りレビュー（`../review-l2.md`）が、実装の外から確かめるために書いた道具です。作業コピーの中の一時ファイルとして作られ、パスは作業コピーのものです。再利用するときは、パスを直してください。

- `e2e/`: 打刻CSVから `report` までの道筋を、仕様の文から書いたモデルと突き合わせる。`check` と `leave` の突き合わせも
- `json/`: ケースのJSONの細部34通り（BOM、`-0`、サロゲート、入れ子の深さなど）
- `fuzz/`: 壊した入力を与えるファジング
- `mut/`: 変異26件の定義（`tools/mutations/cli-review.json` に取り込んだもの）と結果

読み取り専用の確認の道具で、製品のコードではありません。
