# 機能の一覧と、まだ無いもの

何ができるかを、段階ごとに並べます。仕様は `docs/spec/`、受け入れ条件の番号（`AC-nn.n`）が試験との対応です。

## Phase 0: 計算の部品とコマンドライン（この版）

| 機能 | コマンド | 仕様 |
|---|---|---|
| 時間の区分（法定内・時間外・法定休日・深夜・60時間超） | `kintai report` `explain` `case` | [区分](spec/classify.md)、[60時間超](spec/over60.md) |
| 打刻CSVの取込と、勤務への対（異常の検出つき） | `kintai report` `check` | [打刻](spec/punch.md) |
| 休憩の不足の警告（自動では控除しない） | `kintai report` `check` | [打刻](spec/punch.md) |
| 月次の集計（賃金台帳に書く勤怠の項目）、30分丸め | `kintai report` | [月次の集計](spec/report.md) |
| 36協定の上限の判定 | `kintai check` `case` | [36協定](spec/limits36.md) |
| 年次有給休暇（付与、失効、残数、年5日、管理簿） | `kintai leave` `case` | [年休](spec/leave.md) |
| 保存期限の目安 | `kintai retention` | [月次の集計](spec/report.md) |
| 国民の祝日 | `kintai explain` | [祝日](spec/holidays.md) |
| 合成データでの一通りの実演 | `kintai demo` | [コマンド](spec/cli.md) |

`report` `leave` `explain` は、人が読む形（既定）とJSONを選べ、`report` はCSVも選べます。`check` と `retention` は、この版では人が読む形だけです（[出力の形](spec/cli-output.md)）。ケースのJSON（`kintai case`）は、別の実装との突き合わせに使う、入力と出力の唯一の約束です（[区分](spec/case-format.md)、[36協定・年休](spec/case-format-36-leave.md)）。

## 計算せず、拒否するもの

通常の労働時間制だけを扱います。次の指定があると、黙って通常制で計算せず、条文を添えて終了コード3で止めます（[一覧](spec/unsupported.md)）。

- 変形労働時間制（1か月・1年・1週間）、フレックスタイム制、裁量労働制、事業場外みなし
- 管理監督者、農業・水産、監視・断続的労働、宿日直、高度プロフェッショナル
- 年少者、妊産婦、自動車運転、医師、災害復旧の建設、有害業務、研究開発
- 法定休日を特定していない方針、4週4日の休日、継続24時間の例外、休日の振替
- 深夜の時間帯を23時〜6時とする指定、週44時間の確認なしの選択

年休は、時間単位、分割付与、年間の所定労働日数が48日未満（または年間の日数がなく週の所定労働日数が0日）も拒否します。

## 考慮していないこと（出力の `notices` に毎回書く）

休日の振替、他の事業場・他社の労働時間の通算（労基法38条1項）、災害等の臨時の必要による労働（33条）。週の超過を後ろの時間に割り当てる規則は、公的資料が直接定めていない製品の規則です。
