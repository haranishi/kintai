# 仕様: 対応外の働き方は、黙って計算せず、拒否する

Phase 0 は通常の労働時間制だけを扱います。次の働き方を通常制として計算すると、時間外の判定が変わります。法令違反が隠れます。方針に、これらの働き方が指定されているときは、計算を拒否して、拒否の理由（条文）を返します。終了コードは3です。指定の仕方と判定の順序は[検査の順序](validation.md)にあります。

| コード | 働き方 | 根拠 | 通常制と違う点 |
|---|---|---|---|
| `VariableMonthly` | 1か月単位の変形労働時間制 | 労基法32条の2 | 日・週の枠が、定めた労働時間に変わる |
| `VariableYearly` | 1年単位の変形労働時間制 | 32条の4 | 同上。対象期間が3か月を超えるときは、時間外の上限（月42時間・年320時間）も変わる |
| `VariableWeeklyIrregular` | 1週間単位の非定型的変形労働時間制 | 32条の5 | 1日の枠が10時間になる |
| `Flex` | フレックスタイム制 | 32条の3 | 清算期間の総枠で時間外を判定する |
| `DiscretionaryDeemed` | 専門業務型・企画業務型の裁量労働制 | 38条の3・38条の4 | みなし時間で数える |
| `OffsiteDeemed` | 事業場外みなし労働時間制 | 38条の2 | みなし時間で数える |
| `Managerial` | 監督・管理の地位にある者、機密の事務を取り扱う者 | 41条2号 | 労働時間・休憩・休日の規定の適用外。深夜の規定は適用される |
| `AgricultureExempt` | 農業・畜産・養蚕・水産の事業に従事する者 | 41条1号 | 労働時間・休憩・休日の規定の適用外 |
| `SurveillanceIntermittent` | 監視・断続的労働で、行政官庁の許可を受けた者 | 41条3号 | 許可の範囲で、労働時間・休憩・休日の規定の適用外 |
| `NightDutyPermit` | 宿直・日直勤務で、許可を受けたもの | 41条3号、労基則23条 | 許可の範囲で、労働時間等の規定の適用外 |
| `HighlyProfessional` | 高度プロフェッショナル制度 | 41条の2 | 労働時間・休憩・休日・深夜の規定の適用外 |
| `Minor` | 18歳未満の年少者 | 60条・61条 | 時間外・休日・深夜の制限が別にある |
| `PregnantOrPostpartum` | 妊産婦の請求による制限 | 66条 | 請求により時間外・休日・深夜が制限される |
| `AutomobileDriver` | 自動車運転の業務 | 附則140条 | 36協定の上限が別になる（年960時間など） |
| `Physician` | 医業に従事する医師 | 附則141条 | 36協定の上限が別になる |
| `DisasterRecoveryConstruction` | 建設の事業のうち、災害時の復旧・復興の事業 | 附則139条1項 | 月100時間未満・2〜6か月平均80時間の規制が適用されない |
| `HazardousWork` | 坑内労働その他の健康上特に有害な業務 | 36条6項1号、労基則18条 | 1日の時間外が2時間までに制限される |
| `ResearchDevelopment` | 新たな技術・商品・役務の研究開発業務 | 36条11項 | 36協定の上限の一部が適用されない |
| `LegalHolidayUnspecified` | 法定休日を特定していない方針 | 35条、調査Aの記録 | 週の中でどの休日が法定休日かが、働いた日で変わる |
| `FourWeekHolidays` | 4週4日の変形週休制 | 35条2項 | 4週間の起算日と、割増対象日の選定が要る |
| `ContinuousRotation` | 継続24時間の休日の例外（番方編成の交替制） | 通達（調査Aの記録） | 暦日でなく継続24時間で休日を数える |
| `HolidaySwap` | 休日の振替 | 35条、厚労省『時間外・休日労働と割増賃金』 | 振替で勤務日になった元の法定休日の労働は、休日労働でなく平日の労働として数える |
| `NightWindowOverride` | 深夜の時間帯を午後11時〜午前6時とする指定 | 37条4項 | 深夜の区間が変わる |
| `Weekly44WithoutConfirmation` | 週44時間を、確認なしに選んだ方針 | 労基則25条の2 | 対象事業・10人未満の確認が要る |
| `MonthStartDayMismatch` | 60時間超と36協定で、月の起算日が違う方針 | 平成21年基発0529001号、Q&A 2-27 | この版は両者に同じ起算日しか使えない |

計算できる業務でも、次は考慮していない。`report` `check` `leave` `explain` の出力の `notices` に必ず示す（区分のケースの出力 `kintai.classify.v1` には欄を作らない）: 休日の振替（振替の指定がないとき）、他の事業場・他社での労働時間の通算（38条1項）、災害等の臨時の必要による時間外・休日労働（33条）。一般の建設、砂糖製造（鹿児島・沖縄）は、2024-04-01から一般の上限がすべて適用されるので、通常制として計算できる（猶予は終わった）。専用の値は無く、`worker_kind` は `standard` のままにする（`construction` や `sugar_manufacturing` という値は、知らない値で不正な入力）。読み取りだけで対応外を見抜くことは、ソフトにはできない。

## 受け入れ条件

- AC-11.1 [rust] 上の表のコードごとに、該当する指定があると、計算を拒否して終了コード3にする。
- AC-11.2 [rust] 拒否のエラーに、コードと条文を含める。
- AC-11.3 [rust] `legal_holiday_weekday` のない方針は、`LegalHolidayUnspecified` で拒否する。
- AC-11.4 [rust] 拒否した従業員の分を、黙って0や通常制として出さない。
- AC-11.5 [manual] 表のコードが、調査の記録（track-A・track-B）と査読（review-l1）の根拠と対応している。
