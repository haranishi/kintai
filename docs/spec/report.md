# 仕様: 月次の集計（賃金台帳向けの勤怠項目）、丸め、保存の目安

賃金台帳に記入する勤怠の項目（労基法108条、労基則54条）を、従業員ごと・月の期間ごとに出します。賃金の額や氏名などの項目は含みません。根拠は `.agent-harness/runs/2026-10-15-phase0/research/track-B.md` のQ5と、track-AのQ5・Q7です。

## 出す項目（`ledger`）

| 項目 | 意味 |
|---|---|
| `work_days` | 労働日数。実労働が1分以上ある労働日の数。年休の日は含めない（台帳での扱いが公的資料で確定していないため、別の項目 `leave_days` に出す。休暇の入力を渡す版（Phase 1）で出し、この版では作らない） |
| `work_minutes` | 労働時間数。時間外・休日労働を含む総実労働 |
| `overtime_minutes` | 延長時間数。法定外の時間外。**法定休日労働を含まない** |
| `over60_minutes` | `overtime_minutes` の内数。月60時間超 |
| `holiday_minutes` | 休日労働時間数。法定休日の労働 |
| `night_minutes` | 深夜労働時間数。他の項目と重なる独立の項目で、`work_minutes` に足さない |
| `within_minutes`, `extra_within_minutes` | 法定内、その内数の所定外法定内（日ごとに所定労働時間を引く簡易な値で、所定休日の勤務の扱いは契約による。契約上の割増の判断の参考にとどめる） |

`work_minutes = within + overtime + holiday`。就業規則で法の定めと異なる所定時間や休日を定めた場合に、台帳の延長欄を所定外で代えることは、施行規則が認めている（労基則54条2項）。ただしその数字を36協定の検査に使わない。36協定は法定外のOとHで検査する。

## 丸め

方針の `rounding` は `none`（既定）か `monthly_30min`。後者のとき、`overtime_minutes`、`holiday_minutes`、`night_minutes` のそれぞれの月合計を、30分未満切り捨て・30分以上切り上げで時間に直した値を `rounded`（時間）に出す。元の分は変えない。60時間超の分は丸めない（率別の小計の丸めを通達が認めるか確認できていない）。1日ごとの切り捨ては、設定にも存在しない。通達が認めていない。

## 警告と記録

結果に次を付ける。計算に使わなかった事情として、`notices` に次の固定の文を付ける: `NoHolidaySwap`（休日の振替を考慮していない）、`NoCrossEmployerAggregation`（他の事業場・他社の労働時間を通算していない。労基法38条1項）、`NoEmergencyWork`（災害等の臨時の必要による労働を考慮していない。33条）、`WeeklyAssignmentIsProductRule`（週の超過を後ろの時間に割り当てるのは製品の規則）。`BreakShortage`（休憩の不足、日付と分数）、`AttendanceUnconfirmed`（年休の出勤率が未確認。年休の入力がある `kintai leave` だけに出す）、曖昧さの記録（`use_default` のときだけ）。表の最終確認日を `table_checked_on` に出す。専門家の確認前であることを `review_status: "unreviewed"` に出す。

## 保存の目安（`kintai retention`）

保存の最低期間は、労基法109条の5年を、附則143条が当分の間3年にしている。起算日は、賃金台帳が「最後の記入をした日」と「その記録に係る賃金の支払期日」の遅い方、出勤簿やタイムカードなどの重要な書類が「完結の日」と支払期日の遅い方（労基則56条）。労働時間の状況の記録は3年（安衛則52条の7の3）で、起算日の定めはなく、製品の決めごととして完了の日から数える（法定の起算日とは言わない）。年休管理簿は付与の期間中と満了後5年が本則で、労基則附則71条により当分の間3年。製品の既定は、どれも5年にする。期限の日付は、民法の規則（初日を入れず起算日の翌日から数え、n年後の応当日の前日に満了し、応当日がなければ月末に満了する）で数える。ふつうは起算日の応当日の当日と同じで、平年の2月28日から数えて期限がうるう年に入るときだけ、1日後（2027-02-28の5年は2032-02-29）になる。自動では削除せず、保存期限の目安の日付を示すだけにする。

`kintai retention --kind <wage-ledger|attendance|status-record|leave-register> --completed <日付> --wage-due <日付>` は、`statutory_current`、`statutory_base`、`product_default` の3つの期限の日付を返す。

## 受け入れ条件

- AC-08.1 [rust] 台帳の項目が、区分の結果から上の定義で出る。`night_minutes` を合計に足さない。
- AC-08.2 [rust] `overtime_minutes` に法定休日労働が入らない。
- AC-08.3 [rust] `monthly_30min` が、29分は切り捨て、30分は切り上げ、60時間超は丸めない。
- AC-08.4 [rust] `rounding` に日ごとの切り捨てを選ぶ道がない（設定の値の検査）。
- AC-08.5 [rust] 保存期限が、種類ごとに計算される。賃金台帳・重要な書類・年休管理簿は起算日の「遅い方」、労働時間の状況の記録は完了の日から数える。
- AC-08.6 [rust] 出力に `table_checked_on` と `review_status` が必ずある。
- AC-08.7 [rust] 従業員IDは `[A-Za-z0-9][A-Za-z0-9._-]{0,63}` に限る（CSV出力で式として実行される文字を防ぐ）。
