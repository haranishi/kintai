# 仕様: 国民の祝日

国民の祝日は、労基法上の法定休日ではありません。祝日に働かせても、それだけでは休日割増の対象になりません（法定休日は方針で指定する）。区分の計算は祝日を使いません。使うのは、`explain` の説明と、所定休日の表示、将来の欠勤の判定です。根拠は `.agent-harness/runs/2026-10-15-phase0/research/track-C.md` のQ7、祝日法2条・3条です。

## データの出所

- 内閣府「国民の祝日について」の公式CSV（`https://www8.cao.go.jp/chosei/shukujitsu/syukujitsu.csv`）。収録は1955-01-01〜2027-11-23。Shift_JIS（CP932）として読める。内閣府は文字コードを明示していない。2026-10-15に取得し、UTF-8にして `docs/legal/sources/syukujitsu-2026-10-15.csv` に置く。元のSHA-256は `cec37a74…964a`。
- 利用条件は公共データ利用規約（第1.0版）で、CC BY 4.0と互換。出典、加工したこと、取得日を表示する。README と出力に出典の1行を付ける。
- 春分日・秋分日は、国立天文台が前年2月に官報で公表する日付が正本。2020〜2027年の16件は、公式の日付と一致することを調査で確認済み。2028〜2050年は、国立天文台の予想表（`docs/legal/sources/equinox-naoj-forecast-2020-2050.csv`、参考値）と近似式が全件一致することを確かめた。2051〜2099年は、公的な表がなく未検証。

## 規則

1. 2条の祝日: 元日(1/1)、成人の日(1月第2月曜)、建国記念の日(2/11)、天皇誕生日(2/23)、春分の日、昭和の日(4/29)、憲法記念日(5/3)、みどりの日(5/4)、こどもの日(5/5)、海の日(7月第3月曜)、山の日(8/11)、敬老の日(9月第3月曜)、秋分の日、スポーツの日(10月第2月曜)、文化の日(11/3)、勤労感謝の日(11/23)。
2. 特例の年: 2020年と2021年は、特別措置法により海の日・スポーツの日・山の日が移動した。公式CSVの日付を使う。
3. 3条2項（振替休日）: 日曜の祝日があれば、その後で最も近い、祝日でない日。
4. 3条3項（国民の休日）: 前日と翌日が祝日で、自身は祝日でない日。**3条による休日は、2条の祝日として扱わず、再帰して計算しない**。土曜が祝日のときの振替はない。
5. 年の範囲: 2020〜2027年は公式CSVの表を使う（`Official`）。2028〜2099年は、上の規則と春分・秋分の近似式で生成し、`Estimated` を付ける。2020年より前は `OutOfRange`。近似式の正しさは、2050年までを国立天文台の予想表で確かめた。2051年以降は未検証で、出力に注意を付ける。
