# 仕様: 月60時間超の時間外

月の時間外が60時間を超えた分は、割増賃金の下限が5割に上がります（労基法37条1項ただし書）。手順は[区分の仕様](classify.md)の5です。ここでは数え方の規則と受け入れ条件を決めます。根拠は `.agent-harness/runs/2026-10-15-phase0/research/track-A.md` のQ6です。

## 規則

- **月の期間**: 方針の `month_start_day`（1〜28、必須）から1か月。起算日は就業規則などで定めるもので、賃金の計算期間と一致させる義務はない。この版は、60時間超と36協定の「1か月」に、同じ起算日を使う。
- **数えるもの**: 法定時間外の分だけ。法定休日の労働は数えない。法定外休日の労働で、日8時間または週の上限を超えた分は数える。所定外法定内（法定内）は数えない。
- **順序**: 月の期間の中で、時間外の分を時刻の順に数える。同じ日の中では、後ろの分から超える。3600分目までは「60時間以下」、3601分目から「60時間超」。
- **リセット**: 月の期間が替わるたびに、累計は0に戻る。
- **深夜との重なり**: 60時間超の分が深夜に重なる部分は、`night_over60` に別に出す（下限は7割5分: 時間外5割と深夜2割5分の合計、労基則20条1項）。
- **企業規模**: 2023-04-01から、中小企業も5割以上になった。分（`over60`）は日付によらず出す。割増率の説明（`explain`）は2023-04-01以降の日付だけに出し、それより前は率を出さず注意を付ける。企業規模では除外しない。
- **代替休暇**: 労基法37条3項の代替休暇の運用は、この版では扱わない。

## 公的な数値例

厚生労働省『改正労働基準法』p.3: 1日が水曜の31日の月。平日は毎日時間外が3時間、11日（土）は4時間、12日（日、法定休日）は2時間働く。週ごとの時間外は、9、19、15、15、15時間。月の累計は9、28、43、58、73時間。月の時間外は4380分で、60時間以下が3600分、60時間超が780分。休日は120分。27日の時間外の3時間目から、60時間超になる。試験データは `vectors/official-examples.json` の `mhlw-60h-leaflet-31day-month` にある（2026年7月で再現）。

## 受け入れ条件

- AC-04.1 [rust] 月の期間ごとに、時間外の累計が3600分を超えた分だけが60時間超になり、期間が替わると累計が戻る。
- AC-04.2 [rust] 3600分ちょうどまでは60時間以下、3601分目から60時間超になる。
- AC-04.3 [rust] 法定休日の労働は数えず、法定外休日で法定時間を超えた分は数える。
- AC-04.4 [rust] 時刻の順に数え、同じ日の中の後ろの分から60時間超になる。
- AC-04.5 [rust] 60時間超で深夜の分が `night_over60` に別に出る。
- AC-04.6 [rust] 公的な数値例（4380分＝3600＋780、休日120分、27日に60分）が一致する。
- AC-04.7 [rust] 月の起算日が1以外（例: 16日）でも、期間が正しく分かれる。
