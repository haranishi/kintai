# 仕様: 日付・分・区間の部品（kintai-core）

`kintai-core` は外部の依存を持たず、入出力もしません。日本にはサマータイムがないので、扱うのは暦の日付と、日本時間の壁時計の分だけです。選んだ理由と限界は[設計](../architecture.md)にあります。

## 型

- **日付**: 西暦の暦日。入力として受け付けるのは2000-01-01〜2099-12-31だけ（範囲外は拒否）。年休の失効日のように、計算の結果が2099年を超えるのは許すので、型そのものは1900〜2200年を持てる。曜日、日数の加減、月末の日数、うるう年を扱う。
- **時点**: 1970-01-01 00:00（日本時間の壁時計）からの整数の分。日付と、その日の何分目か（0〜1439）に分けられる。
- **区間**: 開始 < 終了の半開区間 `[開始, 終了)`。長さは分。交差、重なりの有無、暦日の0:00での分割ができる。
- **表記**: 日付は `YYYY-MM-DD`、時点は `YYYY-MM-DDTHH:MM`（区切りは `T` か空白）。パースと表示は往復で一致する。2月30日、25時、60分などは拒否する。24:00は受け付けない（翌日の0:00と書く）。だから2099-12-31の24:00に終わる勤務は書けない（2100-01-01T00:00は範囲外）。
- **曜日**: 月曜〜日曜。週の起算日（任意の曜日）から数えた何日目か、を求められる。
- **月の期間**: 起算日（1〜28）を与えると、ある日付が属する期間の初日と、次の期間の初日を返す。

## 規則

- 暦の計算は、1年を365日または366日（4で割れ、100で割れず、400で割れるときを除く）とする標準の暦。
- 分の加減は、桁あふれを起こさない（範囲検査）。
- 型は、並べ替えと比較ができ、出力は決定的（同じ値は同じ文字列）。

## 受け入れ条件

- AC-02.1 [rust] 日付の曜日・加減・月末の日数が、`chrono`（開発時のみの依存）と、2000〜2099年の全日付で一致する。
- AC-02.2 [rust] 時点の分の加減と、日付＋分への分解・合成が往復で一致する。
- AC-02.3 [rust] 区間の交差と重なりの判定が、境界（端が接する、1分重なる）で正しい。
- AC-02.4 [rust] 区間を暦日の0:00で分けると、各小片が1つの暦日に収まり、合計の長さが元と一致する。
- AC-02.5 [rust] 日付と時点の表記が往復で一致し、不正な表記（2月30日、25時、24:00、60分）を拒否する。
- AC-02.6 [rust] 入力の範囲外の日付（2000年より前、2099年より後）を拒否する。計算の結果は2200年まで持てる。
- AC-02.7 [rust] 週の起算日と月の期間の初日が、起算日1と16、月をまたぐ、年をまたぐ場合で正しい。
