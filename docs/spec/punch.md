# 仕様: 打刻の取込、勤務と休憩の対、休憩の不足

打刻の列から、勤務（始業から終業）と休憩を作ります。根拠は `.agent-harness/runs/2026-10-15-phase0/research/track-A.md` の Q7・Q8・Q9 です。

## 入力

打刻CSVの列は `employee_id,timestamp,kind`。`timestamp` は `YYYY-MM-DD HH:MM[:SS]` または `YYYY-MM-DDTHH:MM[:SS]`（日本時間）。`kind` は `in` `out` `break_start` `break_end`。文字コードはUTF-8またはShift_JIS。ヘッダ行は必須。従業員ごとに時刻順に並べて処理する。

## 対にする規則

状態は「勤務外」「勤務中」「休憩中」の3つ。許す遷移は次のとおり。

| 今の状態 | 打刻 | 次の状態 |
|---|---|---|
| 勤務外 | `in` | 勤務中 |
| 勤務中 | `break_start` | 休憩中 |
| 休憩中 | `break_end` | 勤務中 |
| 勤務中 | `out` | 勤務外（勤務が1つ完成） |

それ以外の遷移と、対象期間の最後に勤務中のまま終わることは、異常にする。異常の種類は `DuplicateIn` `OutWithoutIn` `BreakStartWithoutIn` `BreakEndWithoutStart` `OutDuringBreak` `OpenShift` `SameTimestamp` `LongShift`。24時間以上続く勤務は `LongShift`、同じ従業員の同時刻の打刻で順序が決まらないものは `SameTimestamp`。異常のある従業員は、その期間の確定集計を拒否し、異常の一覧を返す（黙って除外しない）。

## 秒の扱い

区分の計算は整数の分だけを使う。秒は、取込で次の方針により分にする。

- `worker_favorable`（既定）: `in` と `break_end` は切り捨て、`out` と `break_start` は切り上げる。実労働が実際の時間を下回らない。
- `reject`: 秒が0でない打刻を不正な入力として拒否する。

丸めた結果、前の勤務の終わりが次の勤務の始まりを越える（終業18:00:30→18:01、次の始業18:00:45→18:00）ときは、前の勤務の終わりを次の始業に合わせて切る（その1分は次の勤務の分で、働いた時間は漏れない）。24時間の判定は、丸めたあとの長さで行う。同じ従業員の秒まで同じ打刻は、種別が違っても `SameTimestamp`。

表にない遷移は、近い名前の異常にする: 休憩中の `break_start` は `BreakStartWithoutIn`、勤務中の `break_end` は `BreakEndWithoutStart`、休憩中の `in` は `DuplicateIn`。異常は、渡された打刻の**全体**で見る（範囲の外の異常でも、その従業員の集計を拒否する。直してから集計する）。

1日ごとの端数の切り捨て、15分単位などへの丸めは、機能として持たない。厚生労働省の解説は、1日の労働時間は1分単位で計算し、切り上げは問題ないが切り捨てはできない、と述べる。元の打刻（秒を含む）は、保存する段階（Phase 1）で残す。

## CSVの読み方

ファイルは256MiB、1行は改行を除く4096バイトまで（文字コードを読む前のバイトで数える）。引用符は使えるが、値の中の改行は不可。空の行はファイルの末尾だけ許す。改行でない単独の CR は不可。前後の空白は取り除かない。見出しの列名は大文字・小文字を区別する。見出しだけのファイルは0件、空のファイルは「1行目に見出しがない」。文字コードは、BOM があれば UTF-8 だけで読み、なければ UTF-8 として正しいときは UTF-8、そうでなければ Shift_JIS（Windows の CP932 を含む）。誤りは、大きさ → 行の長さ → 文字コード → 見出し → データの行（上から。1行の中では `employee_id` が先）の順に、最初の1つを返す。休暇CSVの `hours` は値として読み、`LeaveHourly` で拒否するのは使う側。1人あたり1か月1,000件の勤務は、暦の月ごとの `in` の数で数える。履歴CSVの `total_minutes` は0〜44640。

## 休憩の不足の警告

労働日ごとに、実労働（休憩を除く）の合計を L 分とする。必要な休憩は、L ≤ 360 なら0分、360 < L ≤ 480 なら45分、480 < L なら60分。実際の休憩は、勤務の内側にある休憩と、同じ労働日の勤務と勤務の間の空きの合計。実際が必要を下回れば `BreakShortage`（不足の分数つき）の警告にする。8時間ちょうどは45分、8時間1分は60分で、60分に45分を足さない。休憩を自動で控除しない。

## 受け入れ条件

- AC-01.1 [rust] 打刻の列を、上の遷移で勤務と休憩に対にする。
- AC-01.2 [rust] 遷移の外にある打刻と、24時間以上の勤務と、順序の決まらない同時刻を、異常として一覧する。
- AC-01.3 [rust] 異常のある従業員は確定集計を拒否する。
- AC-01.4 [rust] 既定で、開始側は切り捨て、終了側は切り上げて分にする。
- AC-01.5 [rust] `reject` では、秒が0でない打刻を不正な入力にする。
- AC-01.6 [rust] 休憩の必要分数が、360分・361分・480分・481分の境界で正しい。
- AC-01.7 [rust] 休憩を自動で足し引きしない。不足は警告だけにする。
- AC-01.8 [rust] Shift_JISとUTF-8のCSVを読め、列名のないCSVは拒否する。
- AC-01.9 [manual] 日次の切り捨てや15分丸めの機能がない（公開APIに存在しない）。
