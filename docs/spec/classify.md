# 仕様: 時間の区分（通常の労働時間制）

通常の労働時間制（1日8時間、週40時間）の実労働の分を「法定内・時間外・法定休日」に分け、深夜を別に重ねて数えます。根拠の条文と通達は `.agent-harness/runs/2026-10-15-phase0/research/track-A.md` にあります。対応外の働き方は[対応外の仕様](unsupported.md)で拒否します。入出力のJSONは[ケースの形式](case-format.md)です。

## 用語

- **実労働**: 始業から終業までのうち、休憩を除いた分。単位は整数の分。区間は半開 `[開始, 終了)`。
- **暦日**: 0:00から24:00。**労働日**: 継続勤務が2暦日にわたるときは、始業時刻の属する暦日。
- **週**: 週の起算日（方針、既定は日曜）から7暦日。労働日が属する週で数える。
- **月の期間**: 月の起算日（方針、必須）から1か月。労働日が属する期間で数える。
- **法定休日**: 方針で曜日を1つ指定する。指定のない方針は拒否する。暦日の0:00〜24:00が法定休日。

## 手順

1. 各勤務（継続勤務）の実労働の区間を、暦日の0:00で分けて、小片にする。小片は、属する暦日と労働日を持つ。
2. 暦日が法定休日の小片は「法定休日」に分類する。それ以外（法定外休日を含む）は「平日型」にする。
3. 平日型の小片を、労働日ごとに時刻順に並べる。
4. 週ごとに、労働日の順に処理する。**週の途中から打刻がそろっていない入力は、確定集計にしない**（境界の `IncompleteWeek`）。労働日 D の平日型の分を n とする。週の残り枠 r は、`週の上限 − それまでに法定内と数えた分` で、0を下回らない。週の上限は2400分（特例は2640分）。D の先頭 `min(n, 480, r)` 分は「法定内」、残りは全部「時間外」。日8時間超と週超過は区別せず、どちらも時間外。週の超過を日の後ろの分に割り当てる規則は、時刻順に数える製品の規則で、割り当てを直接定めた公的資料はない（専門家に確認する）。
5. 時間外の分を、月の期間ごとに時刻順に数える。累計3600分までは「60時間以下」、それを超えた分は「60時間超」。法定休日は数えない。
6. 法定内の分のうち、所定労働時間（方針）を超える分を「所定外法定内」と呼び、法定内の内数として出す。日ごとに所定労働時間を引く簡易な値で、所定休日の勤務の扱いは契約による。
7. 深夜: 暦日の22:00以上、翌5:00未満に重なる分を、区分と別に数える。法定内・時間外・法定休日それぞれの内数になる。時間外のうち60時間超の深夜も別に出す。

## 境界

- 22:00ちょうどは深夜に入り、5:00ちょうどは入らない。
- 秒は、取込で[打刻の仕様](punch.md)の方針に従い分にしてから、この計算に渡す。
- 「またぐ」とは、勤務の最後の実労働の分（終了の1分前）が、始業と別の暦日にあること。24:00ちょうどに終わる勤務はまたがない。
- 勤務が法定休日の暦日をまたぐ、週の境界をまたぐ、月の期間の境界をまたぐときは、確定集計を拒否する（既定）。方針が `use_default` のときは、上の手順をそのまま適用し、結果に曖昧さの記録（`HolidayBoundary` `WeekBoundary` `MonthBoundary`）を付ける。根拠は、通達が「始業時刻の属する日の労働」と定めるのは日8時間の判定までで、その先の帰属を直接定めた公的資料が確認できていないためです。
- 入力に `data_from`（打刻がそろっている最初の日）があるとき、実労働のある労働日を含む週の起算日が `data_from` より前なら、その週は `IncompleteWeek`（日付は週の起算日）。週の前半が前月のとき、前月の打刻を足すか、`data_from` で「その日々は勤務なし」と明示する。
- 接する2つの勤務（22:00〜24:00と翌0:00〜6:00など）は、つながない。別の勤務で、別の労働日になる。日をまたいで続く勤務は、1つの勤務として入力する。
- 休憩の不足は区分に影響しない。[打刻の仕様](punch.md)で警告する。
