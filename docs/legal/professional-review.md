# 社会保険労務士に確認してほしい点（確認シート）

kintai の計算は、条文と通達の読みに基づく参考値です。専門家の確認は受けていません。出力には毎回 `review_status: "unreviewed"` を付けています。このシートは、確認を頼むときに渡す一覧です。読みが公的な資料だけでは決まらなかった点と、間違ったときの影響を並べました。

## 返してほしい形

行の ID を指して、「問題なし」「直す（こう直す）」「判断できない」のどれかで返してもらいます。返答は日付、確認者の資格、確認した範囲とあわせて `docs/legal/professional-review-log.md` に追記します（まだ無い）。仕様は `docs/spec/` にあり、AC の番号で試験と対応しています。調査の原文は `.agent-harness/runs/2026-10-15-phase0/research/` にあります。
